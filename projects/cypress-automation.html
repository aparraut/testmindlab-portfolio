Cypress Automation Suite

Suite de automatizaciones profesional diseñada para pruebas E2E, UI y API sobre SQL Mind Trainer.

Descripción General

Esta suite Cypress valida flujos reales del usuario dentro de SQL Mind Trainer: autenticación, navegación de niveles, progreso, ranking, validación SQL, errores y respuestas esperadas.

Tipos de Pruebas

  • E2E Testing: login, niveles, progreso, ranking.
  • UI Testing: estados visuales, feedback, errores.
  • API Testing: validación contra endpoints Supabase.
  • Regresión: flujos críticos de usuario.
  • Fixtures: escenarios controlados y mockeados.

La estructura está organizada siguiendo buenas prácticas: pruebas atómicas, soportes reutilizables y fixtures limpias para reproducibilidad.
