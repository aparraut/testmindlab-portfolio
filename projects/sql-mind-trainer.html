SQL Mind Trainer

Case Study técnico — Plataforma diseñada como entorno real de validación SQL y automatización con Cypress.

Resumen del Proyecto

SQL Mind Trainer es una plataforma creada para practicar SQL y validar consultas de forma interactiva mediante un sistema de niveles progresivos. Su diseño permite integrarlo con flujos reales de pruebas automatizadas.

Objetivos Técnicos

  • Crear un entorno replicable para validación SQL.
  • Integrarlo con suites E2E, UI y API.
  • Permitir flujos de autenticación, progreso y ranking.
  • Construir una base real para pruebas automatizadas con Cypress.

Arquitectura del Proyecto

  • Frontend: HTML, CSS, JavaScript.
  • Backend: Supabase (auth, DB, RLS).
  • Validación: Motor de comparación SQL.
  • Automatización: Cypress (E2E, UI, API).

Automatización con Cypress

SQL Mind Trainer funciona como entorno real para pruebas E2E donde se validan flujos completos de usuario, incluyendo niveles, progreso, ranking y validaciones SQL.

  • Validación de respuestas SQL.
  • Flujos de autenticación y sesión.
  • Pruebas UI sobre feedback y navegación.
  • API Testing de Supabase.
  • Fixtures y ambientes controlados.
