SQL Mind Trainer

Plataforma para practicar SQL y validar lógica usando niveles, progreso y ranking. Base real para suites E2E con Cypress.

Resumen del Proyecto

SQL Mind Trainer permite resolver desafíos SQL mediante un sistema progresivo de niveles. Cada nivel evalúa consultas reales y compara la respuesta con una solución esperada.

Fue diseñado como entorno de testing controlado, ideal para automatización E2E, UI y API.

Objetivos Técnicos

  • ✔ Crear un entorno replicable para practicar SQL.
  • ✔ Modelar niveles, progreso y ranking en supabase.
  • ✔ Permitir autenticación real y persistencia.
  • ✔ Integrarse con Cypress para automatización completa.

Arquitectura del Proyecto

  • Frontend: JS vanilla + HTML + CSS.
  • Backend: Supabase (Auth + DB + RLS).
  • Motor SQL: comparación de query vs solución esperada.
  • Automatización: Cypress (E2E, UI, API).

La arquitectura prioriza consistencia y capacidad de reproducir escenarios con precisión para testing avanzado.

Automatización con Cypress

El proyecto sirve como sandbox real para pruebas automatizadas, validando autenticación, navegación, progreso, ranking y respuestas SQL.

  • ✔ Validación de respuestas SQL.
  • ✔ Pruebas de sesión: login / logout.
  • ✔ Navegación UI + feedback al usuario.
  • ✔ API Testing sobre endpoints Supabase.
  • ✔ Fixtures para reproducir escenarios complejos.
